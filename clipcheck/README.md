# ClipCheck: 클립보드 복사 확인 도우미

MES 같은 프로그램에서 **Ctrl+C**를 눌렀을 때 클립보드에 실제로 복사됐는지 **화면 우상단**에 바로 표시해 줍니다.

- 🟩 **복사됨**: 초록색 알림과 함께 복사된 내용 앞부분을 보여 줍니다.
- 🟥 **복사 안 됨!**: Ctrl+C를 눌렀는데 1초 안에 클립보드가 바뀌지 않으면 빨간색 알림과 "띵" 소리가 납니다.

알림은 포커스를 가져가지 않고 마우스 클릭도 그대로 통과하므로 작업에 방해가 되지 않습니다.

## 실행 방법 (둘 중 하나)

### 방법 1: 설치 없이 바로 실행 (추천)
1. `ClipCheck.cs`와 `run.bat`을 같은 폴더에 넣습니다.
2. `run.bat`을 더블클릭합니다.
3. 작업 표시줄 오른쪽 아래 트레이에 아이콘(ⓘ)이 생기면 실행 중인 상태입니다.

### 방법 2: exe 파일로 만들기
1. `ClipCheck.cs`와 `build.bat`을 같은 폴더에 넣습니다.
2. `build.bat`을 더블클릭하면 같은 폴더에 `ClipCheck.exe`가 생깁니다.
3. 이후로는 `ClipCheck.exe`만 실행하면 됩니다.

두 방법 모두 Windows에 기본으로 들어 있는 기능(PowerShell, .NET Framework)만 사용하므로 따로 설치할 프로그램이 없습니다.

## 트레이 아이콘 메뉴 (우클릭)
- **실패 시 소리 내기**: 켜기/끄기
- **마우스로 복사해도 표시**: 우클릭 → 복사로 복사했을 때도 초록 알림을 띄울지 선택
- **통계 초기화**: 아이콘에 마우스를 올리면 나오는 "성공 n / 실패 n" 숫자를 0으로 되돌립니다.
- **종료**

## PC를 켤 때 자동으로 실행하기
`Win + R` → `shell:startup` 입력 → 열린 폴더에 `run.bat`(또는 `ClipCheck.exe`)의 **바로 가기**를 넣습니다.

## 잘 안 될 때
- **MES를 "관리자 권한"으로 실행하고 있다면** ClipCheck도 관리자 권한으로 실행해야 Ctrl+C를 감지할 수 있습니다. (우클릭 → 관리자 권한으로 실행)
- 회사 보안 정책 때문에 `run.bat`이 막히면 방법 2(exe)를 써 보고, 둘 다 막히면 전산팀에 문의하세요.
- 복사가 원래 느린 프로그램이라 정상인데도 빨간색이 뜬다면 `ClipCheck.cs`의 `WaitMs = 1000`을 `1500`이나 `2000`으로 늘리세요.
