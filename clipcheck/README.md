# ClipCheck: 클립보드 복사 확인 도우미

MES 같은 프로그램에서 **Ctrl+C**를 눌렀을 때 클립보드에 **글자(또는 이미지·파일)가 실제로 들어갔는지** 바로 표시해 줍니다. 픽픽·그림판처럼 이미지를 복사하는 프로그램도 "복사됨 (이미지)"로 표시됩니다. 안 들어갔으면 **Ctrl+C를 자동으로 다시 눌러** 줍니다.

- 🟩 **복사됨**: 복사된 내용 앞부분을 보여 줍니다. 재시도해서 성공한 경우에는 "복사됨 (재시도 1번)"처럼 표시됩니다.
- 🟧 **다시 복사 중… (1/3)**: 글자가 안 들어와서 Ctrl+C를 자동으로 다시 누르는 중입니다.
- 🟥 **복사 안 됨!**: 재시도까지 모두 실패한 경우입니다. "띵" 소리와 함께 원인(클립보드 변화 없음 / 글자가 안 들어옴)을 보여 줍니다.

알림은 포커스를 가져가지 않고 마우스 클릭도 그대로 통과합니다.

## 실행 방법
- **ClipCheck.exe**를 더블클릭합니다. (추천)
- 또는 `ClipCheck.cs`와 `run.bat`을 같은 폴더에 넣고 `run.bat`을 실행합니다. 이 방법으로는 "자동 실행" 설정을 쓸 수 없습니다.
- exe를 직접 만들고 싶으면 `ClipCheck.cs`와 `build.bat`을 같은 폴더에 넣고 `build.bat`을 실행합니다.

## 설정 (트레이 아이콘 우클릭)
| 메뉴 | 내용 | 기본값 |
|---|---|---|
| 자동 재시도 | 실패하면 Ctrl+C를 다시 누를 횟수 (끄기 / 2 / 3 / 5번) | 3번 |
| 확인 속도 | Ctrl+C 한 번마다 기다리는 시간 (0.1 / 0.2 / 0.3 / 0.5 / 0.8초) | 0.3초 |
| 알림 위치 | 화면 우상단 / 마우스 커서 옆 | 우상단 |
| 성공 알림 보이는 시간 | 0.5 ~ 3초 | 1초 |
| 실패 알림 보이는 시간 | 1 ~ 5초 | 2초 |
| 복사 내용 미리보기 | 알림에 복사된 글자 앞부분 표시 | 켜짐 |
| 실패 시 소리 내기 | | 켜짐 |
| 마우스로 복사해도 표시 | 우클릭 → 복사 때도 알림 | 켜짐 |
| 파일 복사도 표시 | 탐색기 등에서 파일을 복사할 때도 알림 | 꺼짐 |
| 윈도우 시작 시 자동 실행 | exe로 실행했을 때만 가능 | 꺼짐 |

**확인 속도 팁:** 너무 빠르게 하면, 원격 PC에서 복사 내용이 아직 넘어오는 중인데 다시 눌러서 오히려 실패가 늘 수 있습니다. "다시 복사 중"이 자주 뜨는데 결국 성공한다면 한 단계 느리게 바꿔 보세요.

## 자동 재시도 안전장치
- **잘라내기(Ctrl+X)**는 다시 누르면 위험할 수 있어서 재시도하지 않고, 표시만 합니다.
- **윈도우 탐색기**에서 누른 Ctrl+C는 확인하지 않습니다. (파일 복사는 원래 잘 되고, 아무것도 선택하지 않았을 때 실패 알림이 뜨면 성가시기 때문)
- 그 사이 **다른 창으로 옮겨 가면** 엉뚱한 것이 복사되지 않도록 재시도하지 않습니다.

## 저장하는 것
- 설정값만 `%APPDATA%\ClipCheck\settings.ini`에 저장합니다. **복사한 내용은 어디에도 저장하지 않습니다.**
- "자동 실행"을 켜면 Windows 시작 프로그램 목록(현재 사용자 레지스트리의 Run 항목)에 등록됩니다. 끄면 지워집니다.
- 인터넷 통신은 하지 않습니다.

## 잘 안 될 때
- **MES를 관리자 권한으로 실행하고 있다면** ClipCheck도 관리자 권한으로 실행해야 Ctrl+C를 감지할 수 있습니다.
- 회사 보안 프로그램이 키보드 감시나 키 입력 보내기를 막으면 동작하지 않을 수 있습니다. 이때는 전산팀에 문의하세요.
