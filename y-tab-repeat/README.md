# Y 탭 반복 입력기 (YTabRepeat.exe)

단축키 하나로 **`y` 입력 → `Tab` 4번** 을 **18회** 반복해 주는 윈도우 프로그램입니다.

## 사용법

1. `YTabRepeat.exe` 를 실행합니다. (설치 필요 없음, 파일 하나)
2. 입력하고 싶은 프로그램의 **첫 칸을 마우스로 클릭**합니다.
3. 키보드의 **F8** 을 누르면 시작합니다.
4. 도중에 멈추려면 **F9** 를 누릅니다.

- 창의 **[실행] 버튼**을 눌러도 됩니다. 이때는 **3초 뒤에** 시작하니, 그 사이에 입력할 칸을 클릭하세요.
- 프로그램 창이 다른 창 뒤에 숨어 있어도 F8 / F9 는 동작합니다.

## 설정 (창에서 바로 바꿀 수 있음)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 반복 횟수 | 18 | `y + Tab 4번` 묶음을 몇 번 할지 |
| y 다음 탭 횟수 | 4 | `y` 다음에 Tab 을 몇 번 누를지 |
| 키 사이 간격 | 50 ms | 키를 누르는 사이의 시간. 입력이 빠져먹으면 100~200 으로 늘리세요 |
| 한글 상태에서도 영문 y로 입력 | 꺼짐 | 한글 입력 상태라 `ㅛ` 가 써지면 체크하세요 |

## 이럴 땐 이렇게

- **"Windows의 PC 보호" 파란 창이 뜰 때**: `추가 정보` → `실행` 을 누르면 됩니다. (서명되지 않은 개인용 프로그램이라 뜨는 안내입니다)
- **`ㅛ` 가 입력될 때**: 한/영 키로 영문으로 바꾸거나, 창의 체크박스를 켜세요.
- **입력할 프로그램이 관리자 권한으로 실행 중일 때**: 이 프로그램도 마우스 오른쪽 클릭 → `관리자 권한으로 실행` 해야 키가 들어갑니다.
- **"F8 / F9 키를 등록하지 못했습니다" 가 뜰 때**: 이 프로그램이 이미 하나 켜져 있는지 확인하세요.

## 직접 빌드하기 (개발자용)

Go 1.21 이상이 필요합니다. 리눅스/맥에서도 윈도우용 exe 를 만들 수 있습니다.

```bash
cd y-tab-repeat
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H windowsgui -s -w" -o YTabRepeat.exe .
```

아이콘·버전 정보는 `winres/` 폴더에 있고, 바꾼 뒤에는
`go run github.com/tc-hib/go-winres@latest make --arch amd64` 로 `rsrc_windows_amd64.syso` 를 다시 만듭니다.
